# InterfaceX — The Frontend Workshop

InterfaceX is a visual playground for experimenting with frontend interfaces. Build with reusable UI components, adjust their properties, preview your work, and inspect the code behind the result.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Built with

- React + TypeScript
- Vite
- Tailwind CSS
- Lucide icons

## Project structure

- `src/landing` — marketing page and project dashboard
- `src/editor` — visual editor, canvas, toolbar, code and properties panels
- `src/engine` — component definitions, tree utilities, code generation, analysis and local project storage
